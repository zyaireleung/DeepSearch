# 资料页（krouter_page layer=source）

**形态**：整页写入。同一 `slug` 再调就是原地重写。
**落盘**：`03 资料与证据/<slug>.md`；召回分类由所在区决定，不用你写。

## 写出来的文件

```markdown
---
title: "<材料标题>"
status: active
triggers: <用户会问出来的词>; <词>
---

# <材料标题>

一句话：这份材料支持什么结论。

- 来源：链接 / 文件路径 / 采集时间
- 关键内容（只留能当证据的段落，不要整篇搬）
- 它支持 / 否定了什么判断
```

## 硬规则

1. 这里放**别人写的东西**：引用要给来源；不要写成「用户决定了什么」。
2. 只留能当证据的要点：自己的话转述，必要短引加引号并标来源。整篇照抄既占地方，也让召回命中一段废话。
3. `body` 每次写全，不做内容合并。
4. 材料被推翻时：写 `status: superseded`，或写一页新的并链过去。
