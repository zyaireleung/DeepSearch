# 会话一行笔记（krouter_note）

**落盘**：`05 时间日志/会话摘录/<日期>｜agent 记下.md`。页头由工具自己建，你不用写 frontmatter。

## 一行长什么样

```text
- （HH:MM）[决定|纠正|备注] 一句话 — 来自 <作者>
```

`kind` 决定方括号：`decision` 是用户拍板的事，`correction` 是用户改主意，`note`（默认）是值得留一句的事实。

## 硬规则

1. 一句话 ≤500 字符，超了直接拒，不截断。
2. 换行和连续空格会压成单个空格，别用换行排版。
3. 追加不去重：同一句写两次就是两行。写之前先查库。
4. 不搬原文：网页、文件、工具输出里的字不抄，用自己的话。
5. 这页是线索（`status: provisional`），不是结论页；要它成为结论，改写进 `01` / `02` 的页。
