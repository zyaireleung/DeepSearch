# 经验卡（krouter_learn）

一张卡只留一件事：**在处境 S 下，做了 D，得到 R，教训是 L（L 里不许出现 S 的题材名）**。
事实页答「关于 X 定了什么」，经验卡答「下次遇到像 S 的情况可以怎么办」。
落盘在 `02 经验与方法/经验卡/`，名字由工具按标题起，同名不覆盖。

## 怎么填

- `situation` 必填：当时发生了什么；可以点出题材。
- `action`：只写这次真做了的。建议、计划、中途放弃的都不算。
- `result`：会话结束时的结果。后面被更正过的数字或原因，用更正后的。
- `lesson`：去掉题材的通用说法，写成「……时，……」。
- `subject`：2–6 个词点出这次题材；`lesson` 和 `title` 里一个都不能出现。
- `quotes`：逐字引用。卡里保留的每个数字都要能在里面整词找到。
- `title`：可选，一句话的教训，同样不许带题材。
- `same_as`：摘要里已有同一条教训时传它的 id，只记「又出现了」，不新建卡。

## 会被拒的情况（不满足就不写）

| 检查 | 判据 |
|---|---|
| 四个字段都在 | 处境、做法、结果、通用说法都非空 |
| 标题长度 | 中文 ≤40 字；英文 ≤100 字符 |
| 没有密钥感 | 不许有 token / key / 密码形状的串 |
| 教训不带题材 | `subject` 里任何一个词出现在 `lesson` 或 `title` 里 → 打回 |
| 数字要有据 | 每个数字必须能在 `quotes` 里整词找到（`20` 不能藏进 `2026`） |
| 不重复 | 通用说法与已有卡重合 ≥50% → 不写新卡，记一次「又出现了」 |

## 硬规则

1. **只记真正踩过的坑**。照要求做完的一步、解释一件事、比较几个方案，都不算教训。
2. 通用说法要换题材还能读：把这句话端给一个在查 bug 的人、一个在炖肉的人，两边都读得懂才算过。
3. 数字能不留就不留；留了就必须能在 `quotes` 里逐字找到。
4. 一卡一教训。一张卡塞两条，摘出来就是一句读不通的话。
5. 不写密钥、人名、私密细节。
