# 复盘页（krouter_page layer=review）

**形态**：整页写入。同一 `slug` 再调就是原地重写。
**落盘**：`04 已完成与复盘/<slug>.md`；召回分类由所在区决定，不用你写。

## 写出来的文件

```markdown
---
title: "<这件事叫什么>"
status: active
triggers: <用户会问出来的词>; <词>
---

# <这件事叫什么>

一句话：做完了什么，结果如何。

- 做了什么
- 结果（带可核对的数字）
- 教训（够通用就另起一张经验卡）
- 遗留 / 没做完的
```

## 硬规则

1. **结论要能被核对**：数字、日期、命令都写实，不写「基本完成」。
2. 这里的教训是「这件事的教训」；换成别的题材也成立的那条，另起 `krouter_learn` 的经验卡。
3. `body` 每次写全，不做内容合并。
4. 复盘写错要改：直接整页重写；旧结论作废并留链走 `krouter_correct`。
