# 错误代码映射（error-codes）

> 流程各环节错误的统一代码表。出错时由 `emit_error` 查本表取级别与 detail/impact 骨架，
> 组装完整错误记录写入 `log/<批次>/errors.jsonl`；log.md 写入器只搬运锚点，不加工。
> 本表独立于每次导入存放，log.md 写入时调用本表辅助生成。

| 代码 | 环节 | 错误 | 原因 | 级别 |
|---|---|---|---|---|
| E01 | S0 唯一化 | 源文档命名冲突 | 与已有源文档/条目页重名且自动唯一化失败 | error |
| E02 | S1/S2/S3 | LLM 调用失败 | 超时 / 429 / 网络中断 | error |
| E03 | S1/S2/S3/S4A/S5 | 返回解析失败 | LLM 返回非预期格式（响应存在但 JSON 解析失败；S5 含 binary/placement/merge 解析） | error |
| E04 | S4A | 提取空结果 | LLM 正常返回空数组，无相关内容命中（warn：业务可接受） | warn |
| E05 | S4/S4A/S5 | LLM 调用失败 | 超时 / 429（S5 含 binary/placement/merge 调用失败，merge 降级仍留痕） | error |
| E06 | S5 写入 | 写盘失败 | 磁盘/权限异常 | error |
| E07 | S5 写入 | 校验失败 | 完整性 / placement 覆盖率不达标 | error |
| E08 | S5 向量 | 向量生成失败 | 嵌入服务不可用 / 超时 | error |
| E09 | S5 查重② | 条目名冲突 | 加（wiki）后仍撞（异常数据） | error |

## detail / impact 骨架（出错点组装用，占位符代入 target 与附加信息）

| 代码 | detail 骨架（哪里+什么错） | impact 骨架（后果） |
|---|---|---|
| E01 | 源文档命名冲突：{源文档名} | {源文档名} 未入库，需人工裁决 |
| E02 | LLM 调用失败：{环节} {文档}（{原因}） | {文档} 该阶段结果未完成 |
| E03 | 返回解析失败：{环节} {文档}（{原因}） | 结果丢弃，需重试；原始返回见本批次 llm_responses.jsonl |
| E04 | 提取空结果：S4A {条目名} | {条目名} 条目页未生成 |
| E05 | LLM 调用失败：{环节} {条目名}（{原因}） | {条目名} 无内容提取 |
| E06 | 写盘失败：{条目页名}（{原因}） | 页面未写入（半截文件已清理） |
| E07 | 校验失败：{条目页名}（{校验项}） | 页面不落盘 |
| E08 | 向量生成失败：内容块 {条目页}/{小标题}（{原因}） | [[{条目名}]] 无向量，检索不可及 |

## 变更记录类别（changes.jsonl 用）

| 类别 | 变更说明 | 影响 |
|---|---|---|
| 源文档变更 | S0 唯一化：原名 → 唯一名 | 留空（无特殊） |
| 页面名称变更 | S5 查重②：逻辑名 → 物理名（wiki） | 留空 |
| 页面分类变更 | S5 migrate：分类变更（b1/b2） | 留空 |

## 错误记录格式（errors.jsonl 一行一条）

```json
{"ts":"...","code":"E08","level":"error","stage":"S5向量",
 "target":{"type":"内容块","entry":"...","block":"..."},
 "anchor":"向量生成失败 · 条目/小标题",
 "cause":"embed 请求 8810 超时，重试 2 次后放弃",
 "context":{"model":"WeMM-Embedding-2B-MLX-4bit","dim":1024},
 "impact":"该内容块无向量，检索不可及"}
```

| 字段 | 用途 | 消费者 |
|---|---|---|
| anchor | log.md 表格直接搬运 | 用户 |
| cause / context / impact | AI 诊断"怎么形成、什么影响" | agent |
| ts / stage / target / code | 定位锚点 | 两者 |
