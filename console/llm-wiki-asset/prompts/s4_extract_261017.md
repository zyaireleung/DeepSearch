# 提取内容

## 目标

针对{条目名}结合“板块参考”从原文中提取与其紧密关联的内容，并按规则输出内容块。

## 解释

内容块：一个独立内容单元，包含小标题和正文。
小标题：提取的内容正文梗概。

## 条目名称

{条目名}

## 板块参考

该类别的页面通常由以下板块构成（仅作板块划分的参考，
实际以原文为准，原文没讲到的板块可以不生成，不要为凑覆盖面而编造内容）：

{template_blocks}

## 原文

{content}

## 规则

- 只提取与{条目名}紧密相关的内容，只是有关联关系没有直接的上下衔接关系的内容不做提取；
- 输出数组 = 板块 + 小标题 + 正文；板块选自“板块参考”；
- 同一板块下可提取多个内容块（不同小标题），正文只提取原文实际讲到的内容，不编造、不臆补；
- 仅返回 JSON 数组，不要额外说明。

## 输出

[{"板块": "…", "小标题": "…", "正文": "…"}, …]
