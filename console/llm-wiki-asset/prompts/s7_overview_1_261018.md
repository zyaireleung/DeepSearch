# 生成知识库概览：概要 + 地图

## 目标

基于知识库的分类体系、当前分布与本轮变化，撰写概览文档的【概要】与【地图】两节，说明这个知识库当前是什么、有哪些东西。

## 解释

知识库：把多份文档中有价值的内容沉淀为可检索、可复用的条目集合。
概览文档：描述知识库当前整体面貌的文档——是什么、有哪些内容、正在发生什么变化。

## 规则

先说明本轮变化的来源类型（本轮变化中每条已标注）：

```
create  = 知识库本轮新增的知识点 → 判断"领域迁移"和"变化趋势"时优先采信
update  = 知识库本轮更新的知识点 → 判断"原有知识点是否演进"，"知识张力"和"变化趋势"可以参考这个内容
migrate = 知识库本轮合并的知识点 → 证明更新的内容有重复，或者对原知识点进行和深化和完善
```

【概要】

- 结合 “分类分布和历史概要” 概括知识库当前的整体定位：以哪类为主体、分布呈现什么特征；
- 结合 “本轮变化和历史概要” 指出新出现的主题方向或明显增长的分类（若有）；
- 参考 “历史概要 ”的格式，保持定位描述的前后一致性，结合整体定位和方向变化进行总体概述；
- 字数限制在500字内，不做内容的好坏判断。

【地图】

- 引用 “分类分布和历史概要”：通过总量、各分类的数量及相互占比关系，给出分类分布的简要说明；
- 引用 “分类说明和历史概要”：重新概括每个分类大致承载什么内容；
- 引用 “本轮变化和历史概要”：说明本次的变化和去向；
- 结合以上三个信息和“历史概要“格式，重新对知识库进行整体的架构说明；
- 字数限制在800字内，只做现状描述，不下判断。
